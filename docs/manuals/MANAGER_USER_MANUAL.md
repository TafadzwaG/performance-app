# Manager User Manual

## Purpose

This guide is for line managers responsible for reviewing employee appraisals, scoring performance, and moving records forward.

## What You Are Responsible For

- helping shape quality objectives during planning
- reviewing employee self assessments
- rating objectives and competencies
- providing evidence-based comments
- sending appraisals back when correction is needed
- submitting completed reviews for approval
- agreeing development actions with employees

## Core Manager Actions

### Review planning quality

Check that:

- objectives are SMART
- weights total `100`
- targets are measurable
- evidence sources are realistic

### Complete manager review

For each appraisal:

- review employee comments and evidence
- record manager ratings
- add concise comments
- rate competencies and values

### Use send-back carefully

Send back only when the employee or earlier stage needs correction. Include a clear explanation of what must be fixed.

### Submit forward

Once the review is complete and consistent, submit the appraisal to the approving manager.

## Good Practice Tips

- base ratings on evidence, not impressions
- keep comments specific and constructive
- use development plans to turn weak areas into concrete actions
- finish reviews before approval deadlines
