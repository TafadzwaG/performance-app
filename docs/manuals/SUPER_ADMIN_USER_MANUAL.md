# Super Admin / System Owner Manual

## Purpose

This guide is for system owners and super administrators who oversee governance, permissions, support, and visibility.

## What You Are Responsible For

- managing users, roles, and permissions
- overseeing impersonation usage
- reviewing audit trail activity
- supporting administrators and business owners
- maintaining system governance

## Governance Areas

### Access control

Use the roles and users modules to:

- assign permissions
- grant or remove direct permissions
- manage role membership

### Impersonation

Impersonation should only be used for support or troubleshooting. Always stop impersonation after the investigation is complete.

### Audit trail

Use the audit trail to review:

- who performed an action
- what route was used
- what was submitted
- when the action occurred

## Good Practice Tips

- avoid granting broad permissions unless necessary
- review privileged access regularly
- use audit evidence when investigating changes
- keep documentation and user manuals current as the system evolves
